# JS CRUD Form

A simple CRUD (Create, Read, Update, Delete) application built using HTML, CSS, and JavaScript.

---

## Project Features

### Form Fields
- Name
- Email
- Gender
- Hobbies
- Age
- State
- City

### CRUD Operations
- Add new records
- Display records in table
- Edit existing records
- Update records
- Delete records
- Cancel update operation

### Additional Functionalities
- Static data display on page load
- Dynamic state and city dropdown
- Search functionality
- Sorting functionality
- Created time for each record

---

## Validation Included

- Required field validation
- Name validation
- Email validation
- Gender validation (Radio button)
- Hobbies validation (Checkbox)
- State and City dropdown validation

---

## Technologies Used

- HTML
- CSS
- JavaScript

---

## Search Functionality

- Search records by name
- Google-like instant search using array methods

---

## Sorting Functionality

Sort records by name:
- Ascending
- Descending
